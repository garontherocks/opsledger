# M2 security and evaluation summary

| Boundary | Enforcement | Limit |
|---|---|---|
| Scope/state authority | SQL/application membership, role and revision before/after inference | Text grants no authority |
| Source visibility | Scoped current-publication/version/hash/body-span validation | Visible sources may contain malicious or false text |
| Local provider | Literal loopback, full digest pin, no redirects, context/deadline/concurrency/response budgets | Locality is not factual safety |
| Output | Strict JSON, deterministic state/IDs, exact citations, plain React text | Correct quote does not prove entailment |
| Derived writes | Editor-scoped index/purge; signed caller/workspace/expiry feedback receipts; append-only decision | No incident state changes or execution |
| Eval egress | Reviewed JS target/grader, remote features off, process API loopback guard | Not an OS/native-code/child-process sandbox |
| Dependencies | Exact lockfile, patched documented overrides, clean install and dated zero-known audit | No universal guarantee |
