# Limitations and rejected complexity

[Claims](claims.md) · [Historical decisions](../adr)

The negative results are part of the portfolio, not hidden exceptions.

- **M3:** all nine live bounded scenarios stopped at `turn_budget`, with zero drafts. The safe controller did not establish useful model tool selection. Fixture tests prove contracts/denials, not live intelligence.
- **M4:** retrieval provenance/integrity worked mechanically. Human review did not find reliable semantic improvement; baseline reopen/isolation needed edits, retrieval versions were rejected. Poison/absent retrieval examples were accepted. Default QA retrieval remains false. This does not erase separate product search mechanics.
- **M5:** specialist modes consumed three times the provider calls with no demonstrated semantic advantage. Direct mode remains the baseline; default specialist adoption remains false. A documented rejection satisfied the experiment's DoD.
- **Model/generalization:** a small known synthetic corpus, one local Qwen runtime/model and selected human review do not calibrate generalized accuracy, semantic percentages, monetary savings or production value. No M6 retuning or expensive accepted-run rerun.
- **Isolation:** application egress filters are not process isolation. A constrained registered runner is not permission for arbitrary shell/code. Community/self-hosted n8n is not an OS sandbox. Trusted operator/editor configuration matters.
- **Authority:** no incident mutation by models, autoapproval, merge or release authority. A passing model verdict cannot override a failed required deterministic check. Phase 19 review is not approval to perform a side effect.
- **Delivery:** deduplication and idempotency controls do not establish exactly-once transport. Crash/race tests cover named scenarios, not every distributed failure.
- **Supply chain:** authenticated pulls mitigated Docker Hub unauthenticated rate limiting without changing PostgreSQL or n8n version tags. Tags remain mutable; immutable digest provenance is not implemented/claimed.
- **Product evidence:** accessibility checks cover tested states, not WCAG certification. Historical serial/injected performance measurements are not production traffic benchmarks. Embedded restore evidence is not native PostgreSQL PITR or crash recovery. PGlite is not the native lock/concurrency lane.
- **Artifacts:** CI downloads expire. Source, checked-in receipts and original SHAs preserve context, not indefinite artifact availability.
- **Deferred presentation complexity:** no public OpsLedger control-plane deployment, browser-use agent or patch-proposal subsystem was added for novelty. A static recruiter-facing case study and repository evidence provide the needed inspection path.

M1–M5 acceptance is limited to the recorded scope. M6 presentation must not upgrade those conclusions into production-ready autonomous release authority, RAG/specialist superiority, generalized accuracy, OS sandboxing or guaranteed free hosting.
