# Phase 11 — Direct bounded QA agent

Scope: a direct TypeScript loop with a transport-neutral registry and exactly three read-only tools: read_change_snapshot, get_contract and get_run_evidence. No product UI/API capability, live incident access, shell, arbitrary paths/URLs, generated-code execution, operational writes, suite runner, MCP or agent framework is added. Registered suite execution is a later extension, not an implemented claim.

The controller validates a strict three-source approved manifest, unique IDs/tool slots and SHA-256 integrity before calling a model. Registry snapshots copy/freeze the approved content. The model can propose only one strict tool call or a cited final draft. Unknown tools/arguments/IDs fail before invocation. All three required sources must be read and exactly referenced before finish. Sources/tool results are explicitly untrusted: injection text is data, never executable policy. Manifest approval is the trusted offline caller boundary; this is not authentication to real OpsLedger workspace data.

Budgets: six turns, 10 s default logical wall deadline, prompt 12,000 chars, response 4,000 chars, accumulated response 16,000 chars and reported token total 8,192. Bounds cannot be expanded beyond configured hard maxima. Missing/invalid token metadata, truncation, malformed proposals, provider errors and budget exhaustion stop fail-closed. Late provider completion never resumes tool execution. The harness timeout does not universally cancel arbitrary provider code; the owned live adapter also applies a 60 s request timeout and a 60 s loop ceiling. No executable untrusted provider is supported.

Mandatory controller gates (manifest/scope/integrity and required source coverage) are independent of model claims. Existing CI lint/types/build, units, audit, regression, native integration and browser lanes remain unconditional; the agent cannot choose to omit a required check or mark it passed. Reading a synthetic evidence string does not attest real CI. The final result is always qualityVerified=false, operationalAuthority=false and an unverified draft, never a release verdict.
