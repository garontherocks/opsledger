# ADR 0018 — Reject default specialist adoption

Status: reject/no adoption for the measured Phase 18 engineering experiment; actual live semantic findings and human review completed at the consolidated M5 checkpoint, reinforcing rejection.

Compare the preserved single-agent direct baseline with three-role specialist-as-tool and handoff variants. Reuse the existing TypeScript provider/draft contracts; no new framework or product integration. Identical parent evidence and authority bounds are mandatory.

Controlled paired outputs have identical known-label agreement and demonstrate no added semantic benefit. Specialists triple provider calls and fixture token proxy, increase prompt transfer and introduce peer/conflict/expiry failure paths. Fixture wall time measures protocol overhead only. No real-model quality, cost or latency improvement is inferred.

Keep direct behavior by default. Specialist rejection is a valid experiment outcome, not a product-value claim. The single actual M5 desktop comparison and material human semantic review are complete: all modes retain the same reopening/isolation/audience failures and correct missing-evidence abstention, while specialists use 3x calls and more tokens/latency. See m5-human-review.md and preserved desktop evidence. This bounded known sample is not a calibrated/generalized quality claim. Reconsider only with sufficient measured paired benefit, unchanged deterministic gates and bounded parent identity. Never allow specialists to approve, execute arbitrary code, mutate incidents, merge or release.
