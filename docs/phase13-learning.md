# Phase 13 learning — accumulated for M3

Skill = reviewed procedure and knowledge, progressively loaded. Prompt = reusable task/context template. Resource = versioned content. Tool = a callable executor capability. MCP = a protocol for exposing these; none of the first four gains permission merely from a name, metadata or convincing prose.

Read the context snapshot: metadata first, selected skill body, selected checklist, exact reviewed MCP prompt, then scoped tool outputs. Every optional context layer is bounded and cannot override controller policy. Hashes prove bytes, not truth or authorization.

Follow the HTTP security matrix: Host/Origin defend endpoint/browser boundaries; token lookup, expiry, audience and scope defend caller access; request IDs reject duplicate requests. A stolen reusable bearer can make a fresh-nonce request, so nonce replay checks are not DPoP. Local-only educational transport is not an OAuth production platform.

Controlled failures: hostile skill metadata fails review; a forged resource blocks transport; a final draft before required reads is denied; unknown shell never reaches MCP; reader deadline aborts the request; invalid scope/audience/expired/revoked credentials fail automatically. None of these deterministic tests establishes semantic model quality.
