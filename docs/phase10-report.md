# Phase 10 — AI/RAG regression and threat gates

Implementation: optional metadata-only quality feedback for server-issued RAG runs, signed caller/workspace/expiry receipts, append-only single-decision persistence, no incident mutation. Existing independent AI/embedding disable flags preserve keyword/timeline fallback. Versioned strict-summary, retrieval and RAG adversarial fixtures are exercised through a local Promptfoo target with a local JavaScript boundary grader and handwritten attacker cases. No model is a safety authority; no remote red-team generation, LLM judge, agent loop, shell tool, model write, paid API or Langfuse deployment is introduced.

The deterministic lane has 19 cases × 2 labeled boundary configurations × 3 repeats = 114 evaluations. All expected boundary outcomes match; zero unexpected egress remains after explicit telemetry suppression. Repeated fixtures are regression evidence, not inference variability, and fixture targets do not react to prompt versions. Contract-valid semantic falsehoods remain visible as failures of bounded literal checks. No prompt-quality improvement or calibrated semantic threshold is claimed.

The opt-in M2 Desktop Validation Bundle runs actual pinned structured summaries, English/Spanish embedding retrieval, two fixed-context RAG prompt versions and end-to-end RAG, in one disposable owned harness. Thirty-six generations use three repeats per case; prompt v2 is a candidate only. Raw/validated/failed results, exact model digests/runtime, source manifests, latency and sampled hardware observations remain in ignored desktop-private evidence. A synthetic Work harness validates the procedure but proves no live-model quality. No repeated desktop deterministic regression suite is requested.

Dependency safety: latest Promptfoo was rejected due an unpatched node-forge path. Exact 0.116.7 plus documented patched overrides passes npm audit with zero known findings and a clean ignore-scripts install. Used JavaScript evaluation paths are compatibility-tested; unrelated vendor adapters are unsupported. A telemetry-disabled event attempted remote egress despite flags; the guard blocked it. A pinned reviewed adapter suppresses that path, and subsequent runs show zero unexpected attempts. The guard covers reviewed Node fetch/http(s)/Socket/DNS APIs and fixed loopback ports, not malicious executable code or a universal OS sandbox. No untrusted provider/grader scripts run.

Validation and remaining gates: see phase10-checks.json. Independent feedback and browser feedback tests pass. A PGlite socket error after a negative constraint assertion was fixed in the test harness by retaining its explicit client and asserting SQLSTATE 23503/23514; security assertions were strengthened, not removed. Native row-lock/least-privilege/multi-worker/restore and remote CI gates remain separately identified. The fallback Chromium 143 renders the login focus-outline golden differently despite correct DOM focus/outline; the existing visual baseline was not changed, tolerance was not widened, and a compatible CI browser result is required. No full browser/visual pass or full M2 closure is claimed until that gate is resolved.

Learning and material semantic review are consolidated at M2. Stop before Phase 11. Do not promote model quality or proceed M3 from a fixture score alone.
